BinMate – marketing site
========================

index.html is a single, self-contained file: all images, styles and the
favicon are embedded inside it. There is no folder structure to keep intact.

HOW TO VIEW
  Double-click index.html. It opens in your browser and works offline.

HOW TO PUBLISH
  Upload index.html to any static host (Netlify Drop, Vercel, GitHub Pages,
  Cloudflare Pages, or a normal web hotel). Rename it to index.html if needed
  so it is served as the start page.

Built with Astro + Tailwind CSS. Source lives in the project repository
(src/pages/index.astro, src/layouts/Layout.astro, src/data/sensors.ts).
